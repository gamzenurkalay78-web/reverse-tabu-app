# reverse-tabu-app

Lise düzeyinde bilgisayar ağları kavramlarını, tabu mantığını tersine çevirerek hazine kelimeleriyle açıklama üzerine kurulu eğitsel kelime oyunu

## Grup Üyeleri ve Görev Dağılımı

- İdris → İçerik yönetimi ve üretimi kelime ve hazine terimleri
- Barış → İçerik yönetimi ve üretimi kelime ve hazine terimleri
- Gamzenur → Pedagojik yapı tasarımı ana proje yönetimi
- Seda → Tasarım UI UX ve görsel düzenleme

## Ortak Sorumluluk

Tüm ekip üyeleri proje kapsamında kod geliştirme sürecine aktif olarak katkı sağlamaktadır
